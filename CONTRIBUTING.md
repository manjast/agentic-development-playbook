# Contributing

Thanks for your interest. This repo is intentionally selective; changes should improve clarity and real usefulness without turning the repo into a broader framework.

## How to contribute

- Open an issue for non-trivial changes.
- Keep edits lean, harness-independent, and easy to understand.
- If you change a rule, update the README and relevant maintained templates or docs.
- Preserve the distinction between evidence, judgment, and acceptance authority.
- Prefer native platform controls over new Playbook-specific infrastructure when they provide the stronger boundary.
- Prefer clarity and demonstrated need over surface-area growth.
- If a proposed addition feels niche, process-heavy, or out of scope for the Playbook's intent, discuss it before opening a PR.
